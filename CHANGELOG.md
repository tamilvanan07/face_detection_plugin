* Initial release of `face_detection_plugin`.
* Added native face detection support for Android.
* Added TensorFlow Lite face embedding extraction (512-dimensional vector).
* Added `FaceCameraView` widget for live camera previews with face detection overlay.
* Added asynchronous native stream callbacks for real-time face embeddings and bounding boxes.
